Matrices (आव्यूह): प्रकार, Operations, Inverse और Rank – B.Sc. Maths Chapter 1 नोट्स

Study Materialअपडेट: 6 नवंबर 2026 · लेखक: Sanjeev Chauhan, University Gyaan

Matrices & Linear Algebra का पहला चैप्टर पूरी किताब की नींव है। यहाँ matrix के प्रकार, operations, inverse और rank के मुख्य नियम हल किए हुए उदाहरणों के साथ दिए हैं।

1. Matrix क्या है?

पंक्तियों (rows) और स्तंभों (columns) में सजाई गई संख्याओं की आयताकार सारणी को matrix (आव्यूह) कहते हैं। m पंक्ति और n स्तंभ वाले matrix को m × n क्रम (order) का matrix कहते हैं।

2. Matrix के मुख्य प्रकार

  • वर्ग आव्यूह (Square): पंक्तियों और स्तंभों की संख्या बराबर।
  • विकर्ण (Diagonal): मुख्य विकर्ण के बाहर सभी अवयव शून्य।
  • इकाई (Identity), I: विकर्ण पर 1 और बाकी 0। किसी भी matrix A के लिए AI = IA = A।
  • शून्य (Null/Zero): सभी अवयव 0।
  • सममित (Symmetric): A' = A।
  • विषम सममित (Skew-symmetric): A' = −A। इसके विकर्ण के सभी अवयव 0 होते हैं।
  • लंबकोणीय (Orthogonal): AA' = I।

याद रखिए: हर वर्ग matrix को एक सममित और एक विषम सममित matrix के योग के रूप में लिखा जा सकता है: A = ½(A + A') + ½(A − A')।

3. Operations के नियम

  • जोड़ और घटाव सिर्फ़ तभी संभव है जब दोनों matrix का क्रम समान हो।
  • गुणा AB तभी संभव है जब A के स्तंभों की संख्या B की पंक्तियों की संख्या के बराबर हो।
  • सामान्यतः AB ≠ BA। यानी matrix गुणा क्रमविनिमेय (commutative) नहीं है।
  • (AB)' = B'A' और (AB)⁻¹ = B⁻¹A⁻¹।

4. Determinant, Adjoint और Inverse

2 × 2 matrix A = [[a, b], [c, d]] के लिए |A| = ad − bc। Inverse तभी होता है जब |A| ≠ 0 हो (non-singular matrix)।

सूत्र: A⁻¹ = adj(A) / |A|, जहाँ adj(A) सहखंडज (cofactor) matrix का transpose है।

हल किया हुआ उदाहरण: A = [[2, 1], [5, 3]] का inverse निकालिए।
|A| = 2×3 − 1×5 = 1। adj(A) = [[3, −1], [−5, 2]]। इसलिए A⁻¹ = [[3, −1], [−5, 2]]।
जाँच: A × A⁻¹ = [[2×3 + 1×(−5), 2×(−1) + 1×2], [5×3 + 3×(−5), 5×(−1) + 3×2]] = [[1, 0], [0, 1]] ✔।

5. Rank (कोटि) और Echelon Form

किसी matrix की rank उसके सबसे बड़े ऐसे वर्ग उपआव्यूह (square sub-matrix) का क्रम है जिसका determinant शून्य न हो। Rank निकालने का आसान तरीका पंक्ति संक्रियाएँ (row operations) लगाकर matrix को echelon form में लाना है। गैर-शून्य पंक्तियों की संख्या ही rank होती है।

उदाहरण: A = [[1, 2, 3], [2, 4, 6], [1, 1, 1]]।
R₂ → R₂ − 2R₁ से दूसरी पंक्ति [0, 0, 0] हो गई। R₃ → R₃ − R₁ से तीसरी पंक्ति [0, −1, −2] बनी। अब गैर-शून्य पंक्तियाँ दो हैं, इसलिए rank = 2।

6. रैखिक समीकरण निकाय (AX = B)

  • यदि rank(A) = rank([A|B]) = अज्ञातों की संख्या, तो अद्वितीय हल।
  • यदि rank(A) = rank([A|B]) < अज्ञातों की संख्या, तो अनंत हल।
  • यदि rank(A) ≠ rank([A|B]), तो निकाय असंगत (inconsistent), कोई हल नहीं।
  • समघात निकाय AX = 0 में हमेशा कम से कम शून्य हल (trivial solution) होता है।

Practice Questions

1. यदि A सममित है तो A' क्या होगा?

उत्तर: A' = A।

2. [[1, 2], [2, 4]] का inverse होता है या नहीं?

उत्तर: नहीं। |A| = 4 − 4 = 0, यानी यह singular matrix है।

3. विषम सममित matrix के विकर्ण के अवयव क्या होते हैं?

उत्तर: सभी शून्य।

4. 3 × 3 identity matrix की rank क्या है?

उत्तर: 3।

5. (AB)⁻¹ बराबर है?

उत्तर: B⁻¹A⁻¹।

तैयारी के सुझाव

  1. Row operations का अभ्यास रोज़ कुछ सवालों से कीजिए, क्योंकि rank और inverse की गलतियाँ ज़्यादातर गणना की होती हैं।
  2. हर प्रमेय (theorem) का प्रमाण एक बार खुद लिखकर देखिए।
  3. Exercise के सवाल पहले खुद हल कीजिए, फिर solution से मिलाइए।

अक्सर पूछे जाने वाले सवाल

Singular और non-singular matrix में क्या अंतर है?

Singular matrix का determinant 0 होता है और उसका inverse नहीं होता। Non-singular का determinant शून्य नहीं होता, इसलिए उसका inverse होता है।

Rank निकालने का सबसे आसान तरीका क्या है?

पंक्ति संक्रियाओं से matrix को echelon form में लाकर गैर-शून्य पंक्तियाँ गिनना।

क्या हर matrix का inverse होता है?

नहीं। सिर्फ़ ऐसे वर्ग matrix का, जिसका determinant शून्य न हो।
